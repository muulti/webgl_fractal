This is a personal little experiment. It renders fractal applying recursive functions to complex numbers. Each complex number is made out of part real and part imaginary which are represented as the vertical and horizontal axis respectively.

When you define a maximum number of iterations, you can check if such number is divergent or convergent (after applying the function that many times) relative to a diameter which is a range you can define as well.

Each pixel in the screen has a coordinate (hence a real and imaginary part) and when you measure its divergence you can give it a different color accordingly, giving life to diverse beautiful and infinitely complex sets.
